REQUIRED TEXT TRANSFORMATIONS:

1. Remove Page Numbers and Headers

Pattern Recognition:
- Remove standalone numbers that appear near these strings: "THE TRACKER", "THETRACKER", "The Ultimate Track"
- Remove page numbers at top/bottom of text sections
- Examples to remove: "122 THE TRACKER", "Jersey Devil 121", "Search 227"
- Keep all other numbers that are part of the narrative

2. Fix OCR Spacing Errors in Contractions

Standard Fixes:
didn ' t → didn't
couldn ' t → couldn't  
wouldn ' t → wouldn't
shouldn ' t → shouldn't
can ' t → can't
won ' t → won't
doesn't't → doesn't
isn ' t → isn't
wasn ' t → wasn't
haven ' t → haven't
hadn ' t → hadn't
you ' re → you're
they ' re → they're
we ' re → we're
I ' m → I'm
he ' s → he's
she ' s → she's
it ' s → it's
that ' s → that's

Detection Pattern: Fix ANY instance where an apostrophe has spaces around it within a word

3. Fix Hyphenated Line Breaks

Problem: OCR often breaks words across lines with hyphens
spot-looking → spotlooking (if it's truly one word)
direc-tions → directions  
sur-vival → survival

Rules:
- If hyphenated word at line break is NOT a real compound word, merge it
- Preserve intentional compound words (e.g., "well-known", "self-sufficient")
- Use context to determine if hyphen is OCR artifact or intentional

4. Normalize for TTS Clarity

Numbers:
- Keep numbers as digits for TTS engine to handle (e.g., "1515" stays as "1515")
- Expand special cases:
  - "Ph.D." → "PhD" (remove periods but keep abbreviation)
  - Dates in text narrative can stay numeric

Abbreviations - Expand for Natural Speech:
Mr. → Mister
Mrs. → Missus  
Dr. → Doctor
vs. → versus
etc. → et cetera
e.g. → for example
i.e. → that is

Special Characters to Preserve:
- Em dashes (—) for pauses: keep as is
- Quotation marks: maintain for dialogue
- Ellipsis (...): maintain for dramatic pauses

Special Characters to Remove/Fix:
- Strange unicode artifacts (■, ●, ∙)
- Multiple spaces → single space
- Inconsistent line breaks within paragraphs → join into flowing text
- Excessive newlines (3+) → reduce to double newline (paragraph break)

5. Preserve Narrative Elements

CRITICAL - DO NOT CHANGE:
- Character names
- Dialogue attribution ("he said", "she whispered")
- Descriptive narrative style
- Original word choices and phrasing
- Paragraph structure and breaks
- Chapter/section indicators

6. For Batches 2+: Append to OUTPUT.txt (do not duplicate overlap sentences)

- No special characters that would disrupt TTS flow

- No mid-sentence breaks at chunk boundaries
